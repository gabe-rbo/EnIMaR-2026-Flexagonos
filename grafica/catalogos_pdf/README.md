# Catálogos Completos de Funções Flexionáveis em PDF

Este diretório contém os **catálogos sistemáticos de funções meromorfas flexionáveis** compilados em formato PDF para os quatro tipos canônicos de flexágonos.

---

## 📚 Catálogos Disponíveis

### 1. Hexa-Tetraflexágono (Quadrados, 6 Faces)
- **Arquivo:** [`funcoes-flexionaveis-hexatetraflexagono_catalogo.pdf`](funcoes-flexionaveis-hexatetraflexagono_catalogo.pdf)
- **Descrição:** Catálogo completo para o hexa-tetraflexágono (6 faces quadradas compostas por 4 quadrantes). Apresenta as funções elípticas de Weierstrass $\wp(z; \Lambda)$, seus retratos de fase, planos de corte e o diagrama mecânico de transição entre estados.

### 2. Tri-Tetraflexágono (Quadrados, 3 Faces)
- **Arquivo:** [`funcoes-flexionaveis-tritetraflexagono_catalogo.pdf`](funcoes-flexionaveis-tritetraflexagono_catalogo.pdf)
- **Descrição:** Catálogo para o flexágono clássico de 3 faces quadradas (obtido por tira rasgada e colagem triangular).

### 3. Hexa-Hexaflexágono (Triângulos, 6 Faces)
- **Arquivo:** [`funcoes-flexionaveis-hexahexaflexagono_catalogo.pdf`](funcoes-flexionaveis-hexahexaflexagono_catalogo.pdf)
- **Descrição:** Catálogo para o hexaflexágono de 6 faces triangulares, articulado pelo anel de inteiros de Eisenstein $\mathbb{Z}[\zeta_3]$ com o grupo cíclico $C_3$.

### 4. Tri-Hexaflexágono (Triângulos, 3 Faces)
- **Arquivo:** [`funcoes-flexionaveis-trihexaflexagono_catalogo.pdf`](funcoes-flexionaveis-trihexaflexagono_catalogo.pdf)
- **Descrição:** Catálogo para o tri-hexaflexágono original de Arthur Stone (1939) com funções $C_3$-invariantes.
