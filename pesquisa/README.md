# Diretório `pesquisa`: Artigos, Eventos, Notebooks e Literatura

Este diretório centraliza a produção acadêmica, a documentação pedagógica e a bibliografia do projeto.

---

## Estrutura das Seções

| Pasta | Conteúdo |
| :--- | :--- |
| [`artigo/`](artigo/) | Código-fonte LaTeX completo do artigo científico (28 páginas, 26 figuras) e PDF compilado. |
| [`enimar2026/`](enimar2026/) | Materiais do evento EnIMaR 2026: templates de submissão em LaTeX, resumos e orientações da professora Aniura. |
| [`notebooks/`](notebooks/) | Cadernos interativos Jupyter para exploração didática e pesquisa de coloração de domínio e curvas polares. |
| [`referencias/`](referencias/) | Biblioteca de artigos científicos e livros em PDF organizados por tema (Coloração de Domínio, Flexágonos e Análise Complexa). |
