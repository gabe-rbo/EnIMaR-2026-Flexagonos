## 1. Sobre a modalidade: minicurso ou comunicação oral?

A escolha depende do objetivo principal:

| Critério | Comunicação Oral (15-20 min) | Minicurso (2-4h) |
| :--- | :--- | :--- |
| **Foco** | Apresentar os resultados e o potencial didático | Ensinar os participantes a construir e usar |
| **Interação** | Limitada a perguntas | Prática, com manipulação e discussão |
| **Perfil** | Ideal para divulgar a pesquisa e a ideia | Ideal para formação de professores e aplicação em sala |
| **Exigência** | Resumo conciso | Proposta mais detalhada, com cronograma |

**Sugestão:** Se o objetivo é **mostrar a ideia e gerar interesse** no uso de flexágonos para ensinar conceitos abstratos, a **comunicação oral** pode ser mais adequada. Se a intenção é que os participantes saiam aptos a **reproduzir e adaptar** a atividade em suas próprias aulas, o **minicurso** é mais poderoso.

## 3. Sugestões para as imagens do novo flexágono

Para aproveitar a dinâmica que você descreveu, as imagens precisam ser escolhidas para que a transformação entre faces seja matematicamente significativa. Aqui vão duas sugestões alinhadas com a dinâmica do gráfico que você compartilhou.

### Ideia 1: Representação de Curvas em Coordenadas Polares

Aqui, cada uma das 6 faces seria uma curva polar diferente. A dinâmica do flexágono mostraria relações entre curvas por transformações de reflexão.

| Face | Curva Polar (exemplo) | Dinâmica Observada |
| :--- | :--- | :--- |
| **Face 1** | `r = 2 + 2·cos(θ)` (cardioide, eixo x) | **Ação:** trocar esquerda/direita → reflexão no eixo y; trocar cima/baixo → reflexão no eixo x. |
| **Face 2** | `r = 2 + 2·sen(θ)` (cardioide, eixo y) | Mesma dinâmica, comparar com a Face 1. |
| **Face 3** | `r = 2 + cos(θ)` (cardioide menor) | **Ação:** trocar esquerda/direita → nova curva. |
| **Face 4** | `r = 1` (círculo) | **Ação:** trocar cima/baixo → mesma curva, pois é simétrica. |
| **Face 5** | `r = cos(2θ)` (rosácea de 4 pétalas) | **Ação:** trocar cima/baixo → mesma curva (simétrica). |
| **Face 6** | `r = sen(2θ)` (rosácea de 4 pétalas girada) | **Ação:** trocar esquerda/direita → nova curva. |

**Estratégia didática:** Ao manipular o flexágono, o estudante observa como a reflexão de uma curva polar se relaciona com sua equação, consolidando a ideia de simetria de forma concreta.

### Ideia 2: Coloração de Domínio de Funções de Variável Complexa

A técnica de coloração de domínio (domain coloring) representa funções complexas `f(z) = w` mapeando cor (hue) para o argumento de `w` e brilho para o módulo. É um campo visualmente rico.

**Escolha sugerida:** Trabalhar com **uma única função** mas explorar **6 diferentes paletas de cor e/ou funções de brilho**. A dinâmica do flexágono compararia esses diferentes modos de visualizar a mesma entidade matemática.

| Face | Configuração de Cor | Efeito Visual |
| :--- | :--- | :--- |
| **1** | Paleta padrão (hue = arg, brilho = módulo) | Visualização clássica. |
| **2** | Paleta com cores complementares | Destaca regiões com argumentos opostos. |
| **3** | Brilho = log(módulo) | Enfatiza variações para valores pequenos. |
| **4** | Brilho constante, cor = arg | Mostra apenas a direção do vetor resultante. |
| **5** | Cor = arg, brilho = módulo² | Enfatiza valores grandes. |
| **6** | Aplicar uma rotação de 90° no domínio `z` | Mostra como a função se comporta com uma transformação de entrada. |

**Estratégia didática:** O flexágono se torna um catálogo interativo de diferentes "lentes" para analisar uma mesma função complexa. A transformação entre faces revela como diferentes aspectos da função emergem conforme se altera a representação visual.
