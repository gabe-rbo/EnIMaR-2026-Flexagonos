# Cadernos Jupyter Interativos (`pesquisa/notebooks`)

Este diretório contém os cadernos interativos utilizados para ensino, prototipagem e exploração visual de conceitos matemáticos.

---

## Cadernos Disponíveis

1. **`aula_dcoloring.ipynb`**: Caderno didático completo sobre **Coloração de Domínio**, abordando círculo de cores, fase contínua, zeros, polos e singularidades essenciais.
2. **`aula_dcoloring_codigos_auxilares.ipynb`**: Implementações de apoio com variações de brilho, reticulados de Wegert e funções dente-de-serra (*sawtooth*).
3. **`ImagensColoracaoDominio.ipynb`**: Geração de paletas de alta resolução para funções racionais e especiais.
4. **`imagens_curvas_polares.ipynb` & `curvas_polares.ipynb`**: Estudo e renderização de curvas em coordenadas polares (rosáceas, cardioides, flor de lótus, borboleta) e suas relações de simetria com as dobras dos flexágonos.

---

## Como Executar

Com o ambiente virtual ativo:
```bash
jupyter lab pesquisa/notebooks/
# ou
jupyter notebook pesquisa/notebooks/
```
